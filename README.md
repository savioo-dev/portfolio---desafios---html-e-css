## Resumo dos Conceitos Praticados

Durante os desafios foram praticados conceitos fundamentais de HTML, incluindo a estrutura de uma página, títulos, parágrafos, listas, links, imagens e atributos HTML.

Também foram praticados elementos como `h1`, `h2`, `p`, `ul`, `ol` e `img`, além de atributos como `src`, `alt` e `href`. Os desafios também envolveram a identificação e correção de erros de sintaxe e estrutura HTML.
